# 🧫 ImmunoBench

**ImmunoBench** is an open and interactive benchmark for **immunohistochemistry-driven computational pathology**.  
It provides standardized evaluation across multiple tasks, datasets, and foundation models, aiming to promote transparency, reproducibility, and fair comparison in the pathology foundation model community.  

This website presents comprehensive benchmark results, datasets, and model comparisons through an elegant, responsive dark-mode interface built with **Tailwind CSS** and **Chart.js**.

## 🧠 Key Features

- **Comprehensive Benchmark:** Evaluates foundation models across multi-level pathology tasks (IHC, classification, prognosis, etc.)  
- **Interactive Visualization:** Dynamic charts and metric tables powered by Chart.js  
- **Dataset Transparency:** Public and private datasets with detailed metadata (stain type, patient count, data volume)  
- **Task Explorer:** Clickable task cards displaying AUC, ACC, F1, or C-index metrics  
- **Responsive UI:** Optimized for both desktop and mobile browsers  
- **Theme Switcher:** Built-in dark/light mode for flexible viewing preferences
